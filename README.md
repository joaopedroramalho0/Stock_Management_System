# StockFlow —Inventory Management System

StockFlow is an inventory management system developed in Python. The project focuses on learning software development through practical implementation and continuous improvement.

## Features

- Register new products.
- Search for products by ID.
- Update product information.
- Delete products with confirmation.
- Store inventory data using JSON.
- Interactive command-line menu.

## Technologies

- Python
- JSON
- Git & GitHub

## How to Run

Clone the repository:

```bash
git clone https://github.com/joaopedroramalho0/Stock_Management_System.git
```

Open the project folder:

```bash
cd Stock_Management_System
```

Run the application:

```bash
python main.py
```

The application currently uses a Portuguese-language interface.
